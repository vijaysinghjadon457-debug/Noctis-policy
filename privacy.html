Privacy Policy

Last Updated: September 16, 2026

This Privacy Policy explains how Noctis ("the Bot") collects, stores, and uses information when it is used in Discord servers.

1. Information We Store

Noctis may store the following information in its database:

  • Discord server (guild) IDs
  • Discord user IDs
  • Discord moderator IDs
  • Discord channel IDs
  • Warning reasons and moderation records
  • Vouch records and timestamps
  • Server prefix settings
  • Vouch channel configuration

2. Information We Do Not Intentionally Store

Noctis does not intentionally store passwords, Discord authentication tokens, payment information, email addresses, or IP addresses in its database.

3. How Information Is Used

Stored information is used to provide Noctis features, including:

  • Server prefix configuration
  • Moderation and warning systems
  • Vouch tracking
  • Vouch leaderboards and statistics
  • Command functionality
  • Maintenance and troubleshooting

4. Data Sharing

Noctis does not sell or rent stored information to third parties.

5. Data Retention

Information may remain stored while it is required for the Bot's features. Data may be deleted during database maintenance or when the developer determines that it is no longer required.

6. Data Security

Reasonable measures are used to protect stored information. However, no online system can guarantee absolute security.

7. Server Administrators

Discord server administrators are responsible for configuring Noctis permissions and deciding who can use administrative features.

8. Discord

Noctis operates through Discord. Discord's own policies and terms may also apply when using the Bot.

9. Changes

This Privacy Policy may be updated when Noctis changes its features or data practices. Updated versions will be published on this page.

10. Contact

For questions regarding this Privacy Policy, contact the Noctis developer through the official Discord community or support channel associated with the Bot.
